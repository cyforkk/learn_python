# 练习安排原则

> 不是每篇笔记都要挂一道仓库练习。练习要**对准一个可练的技能点**，难度匹配当前进度。

## 标签含义（重要）

| 标签 | 含义 | **不是** |
|------|------|----------|
| **过关（必做）** | 本阶段最少要完成的题，用来证明核心技能会了 | — |
| **加练（可选）** | 同一技能换场景再写一遍，或小综合；**时间允许再做** | **不是更难、不是进阶必做** |
| **建议** | 动手成本低（跟命令、写一篇记录），推荐但不挡进度 | — |
| **无** | 本篇不布置仓库练习 | — |

**加练 ≠ 更难。**  
很多加练题和过关题难度差不多，只是：

1. **技能已在过关题里练过**（如通讯录 ≈ 成绩字典，都是字典）  
2. **多花时间的换场景/小综合**（如计算器、JSON 待办）  
3. **控制新手负担**：过关线保持短，其余自愿多练  

## 总原则

1. **先学后练**：笔记没读完，不做对应题  
2. **不是篇篇有题**：了解型、铺垫型文章只读  
3. **一道过关题服务一个主技能**  
4. **只完成「过关」即可进入下一阶段**  
5. **`exercises/` 只有题目骨架，禁止放完整答案**；答案只在 `solutions/`  
6. **作业文件里不写测试**；自检在 `exercises/checks/`（可选）  
7. **实现从简**（答案也保持短）：无类型注解、无高级写法  
8. **笔记练习区只写题目要求 + 两个链接**（作业空白 / 答案），**不贴答案代码**  
9. 正文教学示意可以有，但**不要等于作业答案全文**  
10. **list/dict 约定**：内部构造用小写 `list`/`dict`；注释签名可用大写 `List`/`Dict`；从 `keys()`/`values()` 返回列表时最外层 `list()` —— [bugs/2026-07-12-list-dict大小写与list实体化.md](../bugs/2026-07-12-list-dict大小写与list实体化.md)  

## 阶段 1 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 基本数据类型 | **无**（只了解） |
| 输入输出 | **无**（技能并入猜数字） |
| 运算符与表达式 | **无**（技能可在计算器加练里用到） |
| 条件与循环 | **过关** ex04 九九表、ex01 猜数字 |
| 复合类型 | **过关** ex03 成绩；**加练** ex06 通讯录 |
| 字符串方法与格式化 | **无** |
| 函数 | **过关** ex05 等级函数；**加练** ex02 计算器 |
| 作用域 | **无** |

阶段 1 过关 = 笔记读完 + **ex04、ex01、ex03、ex05**。

## 阶段 2 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 文件读写 + 异常处理 | **过关** ex02 安全读（两篇读完再做） |
| 模块与包 | **过关** ex03 小模块 |
| 面向对象入门 | **过关** ex05 Book 类 |
| 常用标准库 | **加练** ex04 列目录、ex06 重命名计划 |
| 推导式 | **无** |
| （综合） | **加练** ex01 JSON 待办 |

阶段 2 过关 = **ex02、ex03、ex05**。

## 阶段 3 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 虚拟环境 / 包管理 | **建议** ex01 |
| 调试技巧 | **建议** ex04 调试日记 |
| PEP8 / 类型注解 / Git | 类型注解 **加练**（可跳过）；PEP8/Git **无**强制题 |
| 测试入门 | **加练** pytest（可整段跳过） |
| 迷你工程 / 进阶三篇 | **加练** |

## 笔记文末「本课衔接」格式（统一）

每篇笔记文末应包含：

1. **上一篇 / 下一篇**（学习路径不断裂）  
2. **本篇练习**  
   - 有过关/加练：只写**题目要求** + 作业链接 + 答案链接（不贴答案代码）  
   - 无独立练习：写清「无新作业」，并说明**和前后哪道题的关系**（如作用域 → 回看 ex05）  
3. **禁止**只丢一个 [exercises/README.md](../stage-1-basics/exercises/README.md) 总表当衔接
