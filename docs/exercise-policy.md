# 练习安排原则

> 不是每篇笔记都要挂一道仓库练习。练习要**对准一个可练的技能点**，难度匹配当前进度。

## 原则

1. **先学后练**：笔记没读完，不做对应题  
2. **不是篇篇有题**：了解型、铺垫型文章只读，不布置仓库练习  
3. **一道题服务一个主技能**：避免一篇笔记挂 3 道综合题  
4. **分必做 / 选做**：新手只完成「必做」即可过关  
5. **作业文件里不写测试**：实现保持最短；自检放在 `exercises/checks/`（可选）  
6. **实现从简**：优先顶层脚本 / 少量函数，不用类型注解、不用高级写法  


## 阶段 1 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 基本数据类型 | **无**（只了解） |
| 输入输出 | **无**（技能并入猜数字） |
| 运算符与表达式 | **无**（技能并入计算器选做） |
| 条件与循环 | **必做** ex04 九九表；**必做** ex01 猜数字 |
| 复合类型 | **必做** ex03 成绩统计；ex06 通讯录为**选做** |
| 字符串方法与格式化 | **无**（写代码时自然用到） |
| 函数 | **必做** ex05 函数重构；ex02 计算器为**选做** |
| 作用域 | **无**（跟函数一起理解即可） |

新手阶段 1 过关 = 笔记读完 + **ex04 + ex01 + ex03 + ex05** 四题行为正确。

## 阶段 2 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 文件读写 + 异常处理 | **必做** ex02 安全读文件（两篇读完再做） |
| 模块与包 | **必做** ex03 小模块 |
| 面向对象入门 | **必做** ex05 Book 类 |
| 常用标准库 | **选做** ex04 列目录 |
| 推导式 | **无**（写法了解即可） |
| （综合） | **选做** ex01 JSON 待办、ex06 批量重命名 |

新手阶段 2 过关 = **ex02 + ex03 + ex05**。

## 阶段 3 怎么排

| 笔记 | 练习安排 |
|------|----------|
| 虚拟环境 / 包管理 | **建议** ex01 跟着命令做一遍 |
| 调试技巧 | **建议** ex04 写一篇踩坑 |
| PEP8 / 类型注解 / Git | **无强制仓库题** |
| 测试入门 | **选做** pytest（可整段跳过） |
| 迷你工程 / 进阶三篇 | **选做** |
