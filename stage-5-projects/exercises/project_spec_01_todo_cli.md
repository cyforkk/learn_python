# 项目规格 01：命令行待办清单

## 功能需求

1. 命令行交互或子命令形式均可  
2. 至少支持：添加任务、列出任务、标记完成、删除  
3. 数据持久化到 JSON 文件（UTF-8）  
4. 重启程序后数据仍在  

## 非功能

- 非法输入有提示，不直接崩溃  
- 有项目级 `README.md` 说明如何运行  
- 代码放在 `projects/todo-cli/`（目录名可自定）

## 加分项

- 简单分类 / 优先级  
- `pytest` 覆盖核心函数  
- 类型注解  

## 验收

- [ ] 演示：添加 2 条 → 完成 1 条 → 退出再进仍正确  
- [ ] README 可让他人复现  

笔记参考：`../notes/Python实战练习.md`（思想可参考，实现请自写）
