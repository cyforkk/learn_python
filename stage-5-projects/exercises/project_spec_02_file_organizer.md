# 项目规格 02：文件夹整理器

## 功能需求

1. 指定一个「源目录」（先用测试用的副本目录！）  
2. 按扩展名分类，移动或复制到 `源目录/images`、`docs`、`others` 等  
3. 打印汇总：各类移动了多少个文件  
4. 对无扩展名文件有明确策略（例如归入 `others`）

## 安全要求

- **默认不要**直接整理重要目录；在 README 写明风险  
- 最好先 `dry-run` 模式：只打印将要执行的操作  

## 技术建议

- `pathlib.Path`  
- 扩展名用 `path.suffix.lower()`  

## 验收

- [ ] 在自建测试文件夹上跑通  
- [ ] dry-run 与真实执行可切换（或分两个命令）  

代码目录建议：`projects/file-organizer/`
