# 踩坑记录：KeyError 取不存在的字典键

- **日期**：2026-07-11
- **阶段**：stage-3 / ex04 调试练习
- **环境**：Python 3.10 / Windows

## 现象

```python
user = {"name": "Ada"}
print(user["email"])
```

报错：

```text
KeyError: 'email'
```

## 原因

字典里只有 `name`，没有 `email` 键；用 `[]` 访问缺失键会抛异常。

## 解决办法

```python
print(user.get("email", "N/A"))
# 或
if "email" in user:
    print(user["email"])
```

## 以后如何避免

- 可选字段统一用 `.get(key, default)`
- 读 Traceback 先看最后一行异常类型和键名
