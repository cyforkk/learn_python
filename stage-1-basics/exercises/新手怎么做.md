# 新手怎么做练习（阶段 1）

## 作业长什么样

| 目录 | 内容 |
|------|------|
| `exercises/ex0x_….py` | **只有题目**（注释里），下面 `# TODO` 等你写 |
| `solutions/ex0x_….py` | **参考答案**，做完再打开 |
| `exercises/checks/` | 可选自检，新手可忽略 |

**不要**把 `exercises` 里的文件当成答案——那是空白作业纸。
