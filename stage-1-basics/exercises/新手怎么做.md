# 新手怎么做练习（阶段 1）

> 读完对应 [notes/](../notes/) 再来。下面比「测试 / --check」重要一万倍。

## 你只需要做到这些

1. 用编辑器打开某个 `ex0x_xxx.py`  
2. 看文件顶部的 **要求 1、2、3…**  
3. 自己写出能跑的程序  
4. 在终端运行：

```bash
python ex01_guess_number.py
```

能按要求打印、能玩、逻辑对，**就算过关**。

## 怎么认出「测试函数」（重要）

练习文件里通常分两截：

| 位置 | 是什么 | 新手怎么办 |
|------|--------|------------|
| 上面的 `main` / 业务函数 | **题目要你写的功能** | 要读、要写 |
| 下面带注释 `【测试 / 自检函数】` 的 `_selfcheck` | **自动检查对错**，不是题目 | **跳过，别改** |
| `if "--check"` 那几行 | 只有加了 `--check` 才跑测试 | 新手运行时**不要**加 `--check` |

看到大段：

```text
# 【测试 / 自检函数 · 新手请跳过，不必读、不必改】
def _selfcheck() -> None:
    assert ...
```

→ 从这里往下都可以先不看。

阶段 3 里若文件名是 `test_xxx.py`、函数名是 `test_xxx`，也全部是测试，业务代码在旁边的 `stats.py` 等文件里。

## 可以先完全不管的东西

| 东西 | 为什么可以不管 |
|------|----------------|
| `python xxx.py --check` | 给学完想自检的人用的，**不是入门必做** |
| 文件底部的 `_selfcheck` | 一堆 `assert`，看起来吓人，以后再学 |
| `def xxx(...) -> str:` 类型注解 | 当普通函数写就行；注解可先当注释忽略 |
| `raise NotImplementedError` | 若你看到答案/骨架里有，换成你的代码即可 |
| 必须拆很多函数 | 猜数字、九九表：**全部写在 `main` 里也可以** |

对照答案时，发现答案拆了 `compare_guess` 之类，那是「写得更干净」的一种写法，**不是你第一版必须写成那样**。

## 卡壳时

1. 回去重读对应笔记里的例子  
2. 自己 `print` 中间结果  
3. 实在不行再打开 `../solutions/` 看 **思路**，合上后自己敲一遍  
4. 报错看 [FAQ](../../docs/faq-common-mistakes.md)

## 以后什么时候再用 `--check`

- 你已经会写函数，也大概知道「对不对」  
- 想快速确认有没有写错  

```bash
python ex04_multiplication_table.py --check
```

打印 `selfcheck OK` 只是加分项，**不等于学习的唯一标准**。
