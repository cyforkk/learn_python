程序的本质是**处理数据**。Python 用不同的数据类型表示数字、文字、真假等。

## 基本类型（本篇重点）

### int — 整数

不带小数点的数字，可以是正数、负数或零。

**变量赋值语法结构：** `变量名 = 值`

```python
age = 25
score = -10
```

Python 的整数没有大小限制，不像其他语言会溢出。

### float — 浮点数

带小数点的数字，用于表示小数。

```python
price = 9.99
pi = 3.14159
```

注意浮点数有精度问题，`0.1 + 0.2` 的结果是 `0.30000000000000004`，不是精确的 `0.3`。需要精确计算时用 `decimal` 模块。

### str — 字符串

用引号括起来的文本，单引号、双引号都行。

```python
name = "张三"
message = 'hello world'
```

常用操作：`+` 拼接，`*` 重复，`len()` 取长度，`f"{name}"` 格式化。

### bool — 布尔值

只有两个值：**True** 和 **False**，用于逻辑判断。

```python
is_active = True
is_admin = False
```

可以直接用于 `if` 条件判断。注意首字母大写，`true` 和 `false` 会报错。

## 复合类型（容器）—— 先了解名字即可

> 下面内容**不必一次练熟**。看完知道「列表用 `[]`、字典用 `{}`」就够。  
> 增删改查、切片、遍历等，放到 [Python复合类型.md](Python复合类型.md) 再学、再做题。

### list — 列表

**最常用的容器**，有序、可变，用方括号表示。

```python
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")  # 添加元素
fruits[0] = "pear"       # 修改元素
```

可变意味着你可以随时增删改元素。支持索引访问、切片、排序等操作。

### tuple — 元组

和列表类似，但**不可变**，用圆括号表示。

```python
point = (3, 5)
rgb = (255, 128, 0)
```

一旦创建就不能修改。适合存放不应变化的数据，如坐标、配置常量。比列表占用内存更少。

### dict — 字典

**键值对**结构，用花括号表示，通过键快速查找值。

```python
person = {"name": "张三", "age": 25, "city": "北京"}
person["name"]   # "张三"
person["email"] = "test@test.com"  # 添加
```

键必须是不可变类型（通常用字符串），值可以是任意类型。查找速度极快，是 Python 中最常用的数据结构之一。

### set — 集合

**无序、不重复**的元素集合，用花括号表示。

```python
tags = {"python", "django", "flask"}
tags.add("fastapi")     # 添加
tags.remove("flask")    # 删除
```

最大特点是**自动去重**。把列表转成集合再转回来就能去掉重复元素。还支持交集、并集等数学集合运算。

## 其他常用类型

### NoneType — 空值

只有一个值 **None**，表示"什么都没有"或"尚未赋值"。

```python
result = None
```

常用于函数默认返回值、初始化变量、表示"没有结果"。

### bytes — 二进制数据

用于处理二进制内容，如文件读写、网络传输。

```python
data = b"hello"
```

## 类型查看与转换

用 **`type()`** 查看任意值的类型，语法结构：`type(对象)`

```python
type(3.14)    # <class 'float'>
type("hello") # <class 'str'>
type([1, 2])  # <class 'list'>
```

类型之间可以**互相转换**，语法结构：`int(值)`、`float(值)`、`str(值)`、`list(值)`

```python
int("25")      # 字符串转整数 → 25
float("3.14")   # 字符串转浮点 → 3.14
str(25)        # 整数转字符串 → "25"
list("abc")    # 字符串转列表 → ['a', 'b', 'c']
```

## 速查表

| 类型 | 符号 | 特点 | 典型用途 |
|---|---|---|---|
| int | 无 | 整数，无大小限制 | 计数、索引 |
| float | `.` | 浮点数，有精度问题 | 科学计算、价格 |
| str | `""` / `''` | 文本，不可变 | 文字处理 |
| bool | True/False | 只有两个值 | 逻辑判断 |
| list | `[]` | 有序、可变 | 通用序列容器 |
| tuple | `()` | 有序、不可变 | 固定数据、坐标 |
| dict | `{}` | 键值对、可变 | 数据映射、配置 |
| set | `{}` | 无序、不重复 | 去重、集合运算 |
| NoneType | None | 空值 | 占位、默认值 |

## 怎么记

**从用途出发记，不要死记语法。** 要存数字用 int 或 float，要存文字用 str，要存一组数据用 list，要存键值映射用 dict，要去重用 set，数据不变用 tuple。实际写代码时，类型的选择往往是由业务场景自然决定的。
