# Python 运算符与表达式：从加减乘除到逻辑判断

## 什么是运算符和表达式

**运算符**是告诉 Python 做什么操作的符号，比如 `+` 表示加法。**表达式**是运算符和值组合在一起的式子，比如 `a + b`，它会计算出一个结果。

Python 的运算符分几大类：**算术运算符、比较运算符、逻辑运算符、赋值运算符、成员运算符、身份运算符**。日常开发中前三类占 90% 的使用量，其余在特定场景下才用。

## 算术运算符

处理数学运算，最基础也最常用。

语法结构：`值1 + 值2` 加、`值1 - 值2` 减、`值1 * 值2` 乘、`值1 / 值2` 除、`值1 // 值2` 整除、`值1 % 值2` 取余、`值1 ** 值2` 幂

```python
5 + 3     # 8   加法
5 - 3     # 2   减法
5 * 3     # 15  乘法
5 / 3     # 1.666...  除法（结果永远是 float）
5 // 3    # 1   整除（取整数部分，向下取整）
5 % 3     # 2   取余（取模）
5 ** 3    # 125 幂运算（5 的 3 次方）
```

**几个容易混淆的点：**

`/` 和 `//` 的区别：`/` 永远返回浮点数，即使整除：`6 / 2` 得 `3.0`。`//` 返回整数：`6 // 2` 得 `3`。负数整除时向**下**取整：`-7 // 2` 得 `-4`，不是 `-3`。

`%` 取余的实际用途：判断奇偶 `n % 2 == 0`、取个位数 `365 % 10` 得 `5`、周期性操作 `day % 7`。

字符串也支持 `+` 和 `*`：

```python
"hello" + " " + "world"   # "hello world"
"ab" * 3                   # "ababab"
```

## 比较运算符

比较两个值，返回 **True** 或 **False**。

语法结构：`值1 == 值2`、`值1 != 值2`、`值1 > 值2`、`值1 < 值2`、`值1 >= 值2`、`值1 <= 值2`

```python
5 == 3    # False  等于（注意是两个等号）
5 != 3    # True   不等于
5 > 3     # True   大于
5 < 3     # False  小于
5 >= 3    # True   大于等于
5 <= 3    # False  小于等于
```

**`==` 和 `=` 的区别：** `=` 是赋值，`==` 是比较。这是初学者最常犯的错误。

Python 支持链式比较，非常直观：

```python
age = 25
18 <= age <= 60   # True，等价于 18 <= age and age <= 60
```

## 逻辑运算符

组合多个布尔判断，返回 True 或 False。

语法结构：`条件1 and 条件2`（与）、`条件1 or 条件2`（或）、`not 条件`（非）

```python
True and False   # False（两个都为 True 才为 True）
True or False    # True（任意一个为 True 就为 True）
not True         # False（取反）
```

用在条件判断中：

```python
age = 25
has_id = True

if age >= 18 and has_id:
    print("可以进入")

if age < 18 or not has_id:
    print("禁止进入")
```

**短路求值：** `and` 如果左边为 False，右边不执行；`or` 如果左边为 True，右边不执行。可以用来做安全判断：

```python
# 如果 user 为 None，不会执行 .get()，避免报错
user = None
name = user and user.get("name")   # None，不会报错

# 设置默认值
name = user.get("name") or "匿名"   # 如果前面为空就用默认值
```

## 赋值运算符

`=` 是基本赋值，还有**复合赋值运算符**，把运算和赋值合并。

语法结构：`变量 = 值` 基本赋值，`变量 += 值` 加后赋值（等同 `变量 = 变量 + 值`），还有 `-=`、`*=`、`/=`、`//=`、`%=`、`**=` 等

```python
x = 10
x += 3    # x = x + 3 → 13
x -= 3    # x = x - 3 → 10
x *= 2    # x = x * 2 → 20
x /= 3    # x = x / 3 → 6.666...
x //= 2   # x = x // 2 → 3.0
x %= 2    # x = x % 2 → 1.0
x **= 2   # x = x ** 2 → 1.0
```

实际开发中 `+=` 用得最多，比如累加计数：

```python
total = 0
for i in range(1, 101):
    total += i    # 等同于 total = total + i
# total = 5050
```

## 成员运算符

判断元素是否在容器中，返回 True 或 False。

语法结构：`元素 in 容器`（存在返回 True），`元素 not in 容器`（不存在返回 True）

```python
3 in [1, 2, 3]            # True
5 not in [1, 2, 3]        # True
"a" in "apple"            # True
"name" in {"name": "张三"} # True（判断的是键）
```

实际用途：

```python
# 判断用户输入是否合法
choice = input("请输入 yes 或 no: ")
if choice in ["yes", "y", "YES"]:
    print("确认")
```

## 身份运算符

`is` 判断两个变量是否指向**同一个对象**，`is not` 判断是否不是同一个对象。

语法结构：`对象1 is 对象2`（同一对象返回 True），`对象1 is not 对象2`（不是同一对象返回 True）

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

a == b    # True（值相等）
a is b    # False（不是同一个对象）
a is c    # True（指向同一个对象）
```

**`==` 和 `is` 的区别：** `==` 比较值是否相等，`is` 比较是否是同一个内存对象。日常用 `==` 就够了。`is` 主要用于判断 `None`：

```python
if x is None:     # 推荐写法
    print("x 是空值")

# 不推荐写 if x == None，虽然能跑，但不符合 Python 惯例
```

## 位运算符

直接操作二进制位，日常开发很少用到，了解即可。

语法结构：`值1 & 值2` 按位与、`值1 | 值2` 按位或、`值1 ^ 值2` 按位异或、`~值` 按位取反、`值 << 位数` 左移、`值 >> 位数` 右移

```python
5 & 3    # 1   按位与
5 | 3    # 7   按位或
5 ^ 3    # 6   按位异或
~5       # -6  按位取反
5 << 1   # 10  左移（相当于乘 2）
5 >> 1   # 2   右移（相当于整除 2）
```

## 运算符优先级

当一个表达式里有多种运算符时，Python 按固定顺序决定谁先算。**优先级从高到低，高的先执行。**

### 按类别从高到低

| 优先级 | 类别 | 运算符 | 说明 |
|---|---|---|---|
| 1 | 括号 | `()` | 最高优先级，强制先算 |
| 2 | 幂运算 | `**` | 优先级最高的算术运算 |
| 3 | 按位取反 | `~` | 一元运算符 |
| 4 | 乘除类 | `*` `/` `//` `%` | 乘、除、整除、取余同级 |
| 5 | 加减类 | `+` `-` | 加、减同级 |
| 6 | 位移 | `<<` `>>` | 位运算，日常少用 |
| 7 | 按位与 | `&` | 位运算 |
| 8 | 按位异或 | `^` | 位运算 |
| 9 | 按位或 | `\|` | 位运算 |
| 10 | 比较运算 | `==` `!=` `>` `<` `>=` `<=` | 所有比较运算同级 |
| 11 | 成员运算 | `in` `not in` | 判断元素是否在容器中 |
| 12 | 逻辑非 | `not` | 一元逻辑运算 |
| 13 | 逻辑与 | `and` | 二元逻辑运算 |
| 14 | 逻辑或 | `or` | 二元逻辑运算 |
| 15 | 条件表达式 | `A if cond else B` | 三元表达式 |
| 16 | 赋值 | `=` `+=` `-=` `*=` `/=` `//=` `%=` `**=` | 优先级最低 |

### 类别间的优先规律

**算术 > 比较 > 逻辑 > 赋值**，记住这个大顺序就够用了：

```python
# 算术先于比较
3 + 2 > 4        # 先算 3+2=5，再算 5>4 → True

# 比较先于逻辑
3 > 2 and 1 < 5  # 先算 3>2=True 和 1<5=True，再算 True and True → True

# 逻辑先于赋值
result = 3 > 2 and 1 < 5  # 先算右边的逻辑表达式，再赋值给 result
```

### 同级运算符从左到右

```python
10 - 3 - 2    # (10-3)-2 = 5，从左到右
10 / 2 * 3    # (10/2)*3 = 15.0，从左到右
```

**例外：幂运算从右到左：**

```python
2 ** 3 ** 2   # 2 ** (3**2) = 2**9 = 512，不是 (2**3)**2
```

### not 的优先级高于 and 和 or

```python
not True and False   # (not True) and False → False and False → False
not True or False    # (not True) or False → False or False → False
```

### and 的优先级高于 or

```python
True or False and False   # True or (False and False) → True or False → True
```

### 不用死记，加括号就行

**拿不准的时候直接加括号**，既明确又不会错：

```python
# 不加括号，靠优先级，容易看错
a + b * c > 10 and d < 5

# 加括号，清晰明确
(a + b * c > 10) and (d < 5)

# 复杂表达式一定要加括号
(score >= 90 and grade == "A") or (score >= 60 and grade == "B")
```

括号让代码意图更清晰，**可读性永远比少写几个字符重要**。

## 速查表

| 类别 | 运算符 | 用途 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `//` `%` `**` | 数学运算 |
| 比较 | `==` `!=` `>` `<` `>=` `<=` | 比较大小 |
| 逻辑 | `and` `or` `not` | 布尔组合 |
| 赋值 | `=` `+=` `-=` `*=` `/=` | 赋值和复合赋值 |
| 成员 | `in` `not in` | 判断元素是否在容器中 |
| 身份 | `is` `is not` | 判断是否同一对象 |
| 位运算 | `&` `|` `^` `~` `<<` `>>` | 二进制操作 |

## 要点

日常开发中真正高频使用的就三类：**算术运算符做数学计算、比较运算符做条件判断、逻辑运算符组合多个条件**。掌握这三类，加上 `+=` 复合赋值和 `in` 成员判断，能覆盖绝大多数编程场景。其余的用到再查也不迟。
