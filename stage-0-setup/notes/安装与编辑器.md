# 安装 Python 与编辑器

## 学完本节你能

- 安装并验证 Python  
- 用 VS Code 或 PyCharm 打开本仓库并运行 `.py`

## 安装 Python

1. 官网下载：https://www.python.org/downloads/  
2. Windows：**Add python.exe to PATH**  
3. 验证：`py -3 --version` 或 `python --version`  
4. 版本：**3.10+ 可学**，推荐 3.11/3.12  

详见 [docs/windows-setup.md](../../docs/windows-setup.md)。

## 编辑器推荐

### VS Code

1. 安装 https://code.visualstudio.com/  
2. 扩展：`Python`（Microsoft）  
3. `文件 → 打开文件夹` 选本仓库根目录  
4. `Ctrl+Shift+P` → `Python: Select Interpreter`

### PyCharm Community

1. 打开仓库为项目  
2. 设置 Project Interpreter 指向系统 Python 或 `.venv`

## 第一次运行

```bash
python stage-0-setup/hello.py
```
