# 编码与控制台（Windows 友好）

## 为什么要管编码

中文读写若编码不一致，会出现乱码或 `UnicodeDecodeError`。

## 统一约定

- 源文件：UTF-8  
- 读写文件：始终写 `encoding="utf-8"`  

```python
from pathlib import Path
Path("a.txt").write_text("你好", encoding="utf-8")
print(Path("a.txt").read_text(encoding="utf-8"))
```

## 控制台

```powershell
chcp 65001
```

VS Code 终端一般默认较友好。

## 路径

```python
from pathlib import Path
p = Path("data") / "file.txt"  # 跨平台
```
