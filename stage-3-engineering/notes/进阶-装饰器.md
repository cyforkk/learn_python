# 进阶：装饰器（入门）

> 阶段：3 之后 · 难度 ⭐⭐⭐ · 先会函数再学  
> 练习：可自写计时装饰器，无强制仓库题

## 是什么

装饰器是「接收函数、返回函数」的语法糖，常用于日志、计时、权限。

```python
import time
from functools import wraps

def timed(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        result = func(*args, **kwargs)
        print(func.__name__, "耗时", time.perf_counter() - t0)
        return result
    return wrapper

@timed
def work():
    sum(range(100000))

work()
```

## 要点

- `@f` 等价于 `func = f(func)`  
- 用 `functools.wraps` 保留原函数元数据  
- 先读懂再写带参数的装饰器
