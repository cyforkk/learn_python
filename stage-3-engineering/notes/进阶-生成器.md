# 进阶：生成器与迭代器（入门）

> 难度 ⭐⭐⭐ · 会 for 循环后再学

## 生成器函数

```python
def countdown(n: int):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)  # 3 2 1
```

- `yield` 产生惰性序列，省内存  
- 生成器表达式：`(x*x for x in range(10))`

## 与列表推导区别

| 列表推导 | 生成器 |
|----------|--------|
| 一次算完占内存 | 按需计算 |
| `[]` | `()` 或 `yield` |
