# 进阶：asyncio 入门（概念级）

> 难度 ⭐⭐⭐ · 先会同步 `requests` 再学  
> 不必第一遍速成就精通

## 为什么需要

大量 IO 等待（网络、磁盘）时，异步可提高并发效率。

```python
import asyncio

async def hello(name: str) -> str:
    await asyncio.sleep(0.1)
    return f"hi {name}"

async def main() -> None:
    a, b = await asyncio.gather(hello("A"), hello("B"))
    print(a, b)

asyncio.run(main())
```

## 要点

- `async def` 定义协程  
- `await` 等待可等待对象  
- `asyncio.run` 入口  
- 库常用 `httpx` / `aiohttp`（第三方面）

## 什么时候先别用

- 脚本逻辑简单、IO 很少 → 同步更清晰  
- CPU 密集计算 → 看多进程，不是 asyncio 银弹
