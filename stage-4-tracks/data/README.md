# 方向：数据分析

## 常见技能

- `pandas`：表格读写与清洗  
- `numpy`：数值计算基础  
- `matplotlib` / `seaborn`：画图  
- Jupyter Notebook（可选）

## 入门资源

- pandas 用户指南：https://pandas.pydata.org/docs/user_guide/index.html  
- 书籍：《利用 Python 进行数据分析》

## 先跑 starter

见 [starter/](starter/)：`pip install -r requirements.txt` → `python main.py`

## 最小 demo 选题

1. 读一份 CSV → 清洗空值 → 分组统计 → 导出结果  
2. 画 2～3 张图并写三句结论  

代码建议路径：`projects/data-demo/`
